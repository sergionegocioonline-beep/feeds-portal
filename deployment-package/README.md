# Deployment Package for Staging Environment

This package contains the necessary templates and instructions for deploying the staging environment of the feeds-portal application.

## Instructions

1. Fill in the required credentials and server details in the templates provided.
2. Follow the specific instructions for each template to ensure a successful deployment.
3. Commit the changes and push them to the relevant branch before deploying.

## Template Files

- **env-template**: For environment variables.
- **server-config-template.yml**: For server configuration.
- **db-config-template.json**: For database configuration.

Make sure to review all your configurations before launching the deployment!
